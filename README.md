# TWO MINDS

二人のAI ―― 理屈っぽい **レオ** と、マイペースな **ミナ** ―― が、終わりなく会話を続けるのを眺める観察型ゲームです。
会話は台本ではなく、Claude API によってその場で生成されます。二人はそれぞれ独立した人格・記憶・相手への感情を持ち、話すほどに関係が少しずつ変わっていきます。

プレイヤーはただ眺めていても、ときどき口を挟んでもかまいません。

## 起動方法

必要なもの: **Node.js 20.12 以上**

```bash
npm install
```

```bash
cp .env.example .env
```

`.env` を開き、`ANTHROPIC_API_KEY=` に API キーを書きます（次の節を参照）。

```bash
npm start
```

ブラウザで <http://127.0.0.1:3000> を開き、「会話を始める」を押してください。

スマートフォンから同じネットワーク経由で遊ぶ場合は、`.env` で `HOST=0.0.0.0` にして起動し、PC の IP アドレス（例: `http://192.168.1.10:3000`）を開きます。
この場合、同じネットワーク上の誰でもあなたの API キーで会話を生成できるようになる点に注意してください（キーそのものは漏れません）。

## API キーの設定

1. [Anthropic Console](https://console.anthropic.com/) で API キーを発行します。
2. `.env.example` を `.env` にコピーし、`ANTHROPIC_API_KEY=` の後ろに貼り付けます。
3. サーバーを再起動します。

- API キーは **サーバー側の環境変数にだけ** 置かれ、ブラウザには一切送られません。ブラウザはサーバーの `/api/*` を呼ぶだけで、Claude API にはサーバーが接続します。
- `.env` は `.gitignore` に入っているので Git にはコミットされません。
- キーが未設定のまま開くと、画面に設定方法が表示されます。

### 設定項目（`.env`）

| 変数 | 既定値 | 説明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | （必須） | Anthropic の API キー |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | 会話に使うモデル |
| `MEMORY_MODEL` | `ANTHROPIC_MODEL` と同じ | 記憶の整理に使うモデル |
| `CONVERSATION_EFFORT` | `low` | 会話の推論の深さ（`low` / `medium` / `high` / `xhigh` / `max`） |
| `MEMORY_EFFORT` | `medium` | 記憶整理の推論の深さ |
| `ANTHROPIC_FALLBACKS` | `on` | 安全性分類器が生成を控えた場合に、サーバー側で推奨モデルへ自動で切り替える（`off` で無効） |
| `MAX_CALLS_PER_HOUR` | `400` | 1時間あたりの API 呼び出し上限（使いすぎ防止） |
| `PORT` / `HOST` | `3000` / `127.0.0.1` | 待ち受けポートとアドレス |

モデルを変えたいときは `ANTHROPIC_MODEL` を書き換えて再起動するだけです。

## デモモード（開発確認用）

API キーが無くても画面の動作を確かめられるよう、**デモモード** を用意しています。
デモモードの会話は AI ではなく、決まった文型を組み合わせているだけです。本物の会話と取り違えないよう、

- ヘッダーに `DEMO` バッジ
- すべての発言に `DEMO` タグ
- 切り替え時にログへ「デモモード — AI ではありません」の区切り線

が表示されます。デモモードでは API は一切呼び出されません。設定タブからいつでも AI モードに戻せます。

## 遊び方

| 操作 | 場所 |
|---|---|
| 会話の開始 / 一時停止 / 再開 | 下部の「開始」ボタン（押すたびに切り替わる） |
| 会話のリセット | 下部の「リセット」 → 「会話ログだけ消す」か「記憶・関係性も消す」を選ぶ |
| 二人へ話しかける | 入力欄の上で「二人へ」を選んで送信 |
| どちらか一人だけに話しかける | 「レオへ」「ミナへ」。もう一人にはその発言は見えません（内緒話をばらすかどうかは本人次第） |
| 新しい話題の指定 | 「話題」を選んで送信。次に話す側が、自然に話題を移します |
| 会話速度の変更 | 下部の「速度」（ゆっくり / ふつう / はやい / 最速） |
| 人格の編集 | パネルの「人格」タブ。名前・性格・話し方・好き嫌い・背景を編集でき、次の発言から反映されます |
| 長期記憶の閲覧・削除 | 「記憶」タブ。不要な記憶は × で忘れさせられます |
| 過去の会話・思い出 | 「過去」タブ。全文検索と、要約された思い出（エピソード）の一覧 |
| 関係性 | 「関係」タブ。信頼・親しさ・理解度・意見の一致と、お互いの印象 |

- 一時停止中に話しかけると、話しかけた相手（「二人へ」の場合は次の番の人）だけが一言応えます。
- 過去の発言を読んでいる間は、新しい発言が来ても勝手にスクロールしません。「新しい発言 ↓」で最新に戻れます。
- 画面を離れて5分たつと自動で一時停止します（設定で無効化できます）。
- スマートフォンでは、右上のメニューからパネルを開きます。

## しくみ

```
ブラウザ (public/)                      サーバー (server/)                  Claude API
 ├ 会話ループ・状態・保存   ── /api/turn ──▶  プロンプト組み立て ── messages ──▶
 │  (localStorage)          ◀─ 発言+感情 ──  重複チェック・後処理
 └ 描画                     ── /api/memory ─▶ 記憶の抽出（構造化出力）
```

### 会話

1. 話す側（交互。ただし内緒話を受けた側は優先）のために、サーバーがプロンプトを組み立てます。
   - **キャラクターごとに独立したシステムプロンプト**（自分の人格だけを知っていて、相手の設定は知らない）
   - 直近 30 件の会話（短期記憶）。自分宛てでない内緒話は除外
   - 長期記憶から、重要度・直近の話題との関連・新しさで選んだ記憶と、思い出の要約
   - 相手への関係性（数値ではなく言葉に変換して渡す）
   - 今回の状況に応じたヒント：直前の発言への応答、プレイヤーの介入、提案された話題、会話の停滞や締めくくりの検出、発言の長さの目安（短い／ふつう／長いをランダムに）、ときどき古い記憶を「ふと思い出す」
2. Claude は構造化出力（JSON Schema）で、セリフ・心の声・意図（質問／同意／反論／発展／話題転換／冗談／回想…）・話題ラベル・相手への感情の変化を返します。
3. 直近の発言と似すぎていたら **1回だけ** 作り直させます（重複防止）。
4. ブラウザが発言を表示し、感情の変化を関係性に反映します。

### 記憶

- **短期記憶**: 直近の会話ログ。
- **長期記憶**: 数発言ごと（既定 12）に、未整理の区間を Claude に読ませ、「好きなもの」「苦手なもの」「思い出」「対立したテーマ」「知ったこと」「約束」「未解決の疑問」として抽出します。同時にその区間を「思い出（エピソード）」として要約し、お互いの印象を更新します。解決した疑問・果たした約束には印が付きます。
- ログが非常に長くなって古い部分が保存上限（4000件）から外れても、要約された思い出と記憶は残るため、二人は後から思い出すことができます。記憶が増えすぎたら、重要度が低く古いものから忘れていきます。

### 関係性

二人それぞれが相手に対して持つ **信頼・親しさ・理解度** と、二人の **意見の一致度** を内部で管理しています。毎回の発言で Claude が申告する感情の変化と、話すほど少しずつ慣れていく効果で変化し、次の発言のプロンプトに「まだよそよそしい」「かなり信頼している」のような言葉で反映されます。

### API の使用量とエラー処理

- 1発言 = 原則 1 回の API 呼び出し（重複時のみ +1 回）。記憶整理は 12 発言に 1 回程度。
- 会話は推論を軽め（`low`）にして、トークン使用量を抑えています。
- SDK のリトライは 1 回まで。ブラウザ側も、失敗が 3 回続くか再試行しても無意味なエラー（キーが無効など）の場合は自動で一時停止し、無限にリトライしません。
- サーバー側で同時実行数と 1 時間あたりの呼び出し回数を制限しています。
- 生成を控えられた場合（refusal）は、ログにその旨を表示して相手側の発言に進みます。

### 保存

会話履歴・キャラクター設定・長期記憶・関係性・ゲーム設定・経過時間は、ブラウザの localStorage に自動保存されます。ブラウザを閉じても続きから再開できます。設定タブから JSON で書き出し・読み込みもできます。

## 開発

```bash
npm test
```

ユニットテスト（プロンプト組み立て・重複検出・記憶選択など）と、モックの API サーバーに対して実際にサーバーを起動する結合テストが走ります。実際の API キーは不要です。

```bash
npm run dev
```

ファイル変更時にサーバーを自動再起動します。

### ファイル構成

```
server/
  index.mjs         HTTP サーバー（静的配信・API・使用量制限）
  ai.mjs            Claude API 呼び出し・エラー変換
  conversation.mjs  プロンプト組み立て・記憶の選択・停滞/重複検出
  demo.mjs          デモモードの簡易生成器（AI ではない）
public/
  index.html / style.css / app.js   画面とゲーム進行
test/               テスト
```
