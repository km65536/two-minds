# TWO MINDS

夜の部屋で、テーブルをはさんで向かい合う二人 ―― 理屈っぽい **レオ** と、マイペースな **ミナ**。
二人は Gemini API によってその場で生成される会話を、延々と続けます。あなたはそれを眺めながら、ときどき画面下から話しかけることができます。

- 2D の画面で、左右の二人が向かい合って話す
- 発言は吹き出しで表示され、話している間は口が動き、表情が変わる
- 二人はそれぞれ独立した人格を持ち、相手の設定は知らない
- 会話が停滞すると、自分から話題を変える
- プレイヤーの発言にも自然に反応する
- 文脈は直近の会話だけ。長期記憶や会話ログは保存しない

## ローカルで起動する

必要なもの: **Node.js 22 以上**

```bash
npm install
```

```bash
cp .env.example .env
```

`.env` の `GEMINI_API_KEY=` に API キーを書いて（次の節）、起動します。

```bash
npm start
```

ブラウザで <http://127.0.0.1:3000> を開き、「会話をはじめる」を押してください。

## API キーの設定（課金されないために）

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを発行します。
2. **請求先アカウント（Billing）を設定していない Google Cloud プロジェクト** のキーを使ってください。
   - Gemini API は、請求先が設定されていないプロジェクトでは無料枠でのみ動作し、上限を超えると課金されずにエラー（429）になります。
   - すでに請求先を設定したプロジェクトのキーを使うと、無料枠を超えた分が課金されるおそれがあります。
3. キーは **サーバーの環境変数にだけ** 置きます（ローカルでは `.env`、Render ではダッシュボード）。ブラウザには一切送られません。`.env` は Git にコミットされません。

モデルは `GEMINI_MODEL` で変更できます（既定: `gemini-3.5-flash-lite`）。無料枠の対象モデルや上限は変わることがあるので、[料金](https://ai.google.dev/gemini-api/docs/pricing) と [レート制限](https://ai.google.dev/gemini-api/docs/rate-limits) のページ、または AI Studio で確認してください。

## Render の無料 Web Service で公開する

### Blueprint（render.yaml）を使う場合

1. このリポジトリを GitHub にプッシュします。
2. Render のダッシュボードで **New → Blueprint** を選び、リポジトリを指定します。
3. `GEMINI_API_KEY` の入力を求められるので、キーを入力します。
4. デプロイが終わると `https://<サービス名>.onrender.com` で遊べます。

### 手動で作る場合

**New → Web Service** でリポジトリを選び、次のように設定します。

| 項目 | 値 |
|---|---|
| Runtime | Node |
| Build Command | `npm ci --omit=dev` |
| Start Command | `npm start` |
| Instance Type | Free |
| Health Check Path | `/healthz` |
| Environment | `GEMINI_API_KEY`（必須）と、必要なら下の表の変数 |

`PORT` は Render が自動で設定し、サーバーは Render 上では自動的に `0.0.0.0` で待ち受けます。

無料インスタンスは 15 分ほどアクセスがないと休止し、次のアクセスで起動します（最初の表示に少し時間がかかります）。

## 使いすぎ・不正利用の防止

公開しても無料枠を超えないよう、何重にも制限しています。

| 対策 | 内容 |
|---|---|
| 課金されないキー | 請求先のないプロジェクトのキーを使えば、無料枠を超えてもエラーになるだけで課金されません（最も重要） |
| サイト全体の上限 | 1 日（太平洋時間）あたり `DAILY_CALL_LIMIT` 回、1 分あたり `RPM_LIMIT` 回まで |
| 接続元ごとの上限 | IP ごとに 1 日 `IP_DAILY_LIMIT` 回、1 分 `IP_RPM_LIMIT` 回、リクエスト間隔は `IP_MIN_INTERVAL_MS` 以上 |
| 同時実行数 | `MAX_CONCURRENT` 件まで |
| リトライしない | SDK の自動リトライは無効。Gemini の 429 も再試行しない |
| 出力の上限 | 1 発言は 100 字程度、`GEMINI_MAX_OUTPUT_TOKENS` で出力を制限。入力は直近 14 発言だけ |
| 見ていないときは止まる | 画面を離れて 20 秒で一時停止（戻ると再開）。操作がないまま 40 発言で「まだ見ていますか？」と一時停止 |
| 他サイトからの利用を拒否 | 専用ヘッダーと Origin を確認し、他サイトのページからの API 呼び出しを拒否。リクエストサイズも制限 |
| 緊急停止 | `AI_ENABLED=false` にすると AI を呼ばず、デモモードだけで動きます |
| 上限に達したら | AI の代わりにデモモード（AI ではないと明示）に切り替えて表示を続けます |

上限の回数はサーバーのメモリ上で数えているので、無料インスタンスが休止・再起動すると数え直しになります。そのため、**最終的な歯止めは「請求先のないキーを使うこと」** です。既定値（1 日 300 回）は Gemini の無料枠より低めにしてありますが、無料枠の上限は変わることがあるので、確認したうえで調整してください。

### 環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `GEMINI_API_KEY` | （必須） | Gemini API キー |
| `GEMINI_MODEL` | `gemini-3.5-flash-lite` | 使用するモデル |
| `GEMINI_MAX_OUTPUT_TOKENS` | `1024` | 1 発言あたりの最大出力トークン数 |
| `AI_ENABLED` | `true` | `false` で AI を止め、デモモードのみにする |
| `DAILY_CALL_LIMIT` | `300` | サイト全体の 1 日あたり呼び出し上限 |
| `RPM_LIMIT` | `10` | サイト全体の 1 分あたり呼び出し上限 |
| `IP_DAILY_LIMIT` | `120` | 接続元ごとの 1 日あたり上限 |
| `IP_RPM_LIMIT` | `8` | 接続元ごとの 1 分あたり上限 |
| `IP_MIN_INTERVAL_MS` | `2500` | 接続元ごとの最小リクエスト間隔 |
| `MAX_CONCURRENT` | `3` | 同時に処理する AI リクエスト数 |
| `PORT` / `HOST` | `3000` / `127.0.0.1`（Render では `0.0.0.0`） | 待ち受けポートとアドレス |

## デモモード

API キーがないとき、AI が止められているとき、上限に達したときは、**デモモード** で動きます。
デモモードの会話は AI ではなく、決まった文型を組み合わせているだけです。本物と取り違えないよう、ヘッダーに `DEMO` バッジ、開始時と切り替え時に「AI ではありません」という表示が出ます。デモモードでは API は一切呼び出されません。

## 遊び方

- 「会話をはじめる」を押すと、二人が話し始めます。
- 画面下の入力欄から話しかけられます（100 字まで）。話しかけると、二人とも順に反応します。
- 右下のボタンで一時停止 / 再開。一時停止中に話しかけると、一人が応えます。

## しくみ

```
ブラウザ (public/)                          サーバー (server/)                Gemini API
 ├ 会話ループ（直近 14 発言だけメモリに保持） ─ /api/turn ─▶ 上限チェック・プロンプト組み立て ─▶
 └ 吹き出し・口パク・表情                    ◀─ セリフ＋表情 ── 重複チェック・後処理
```

1. 交互に、話す側のためにサーバーがプロンプトを組み立てます。
   - 話す側の人格だけを書いた **キャラクターごとのシステム指示**（相手の設定は知らない）
   - 直近の会話
   - 状況に応じたヒント：直前の発言への応答、プレイヤーの発言、停滞や締めくくりの検出と話題の例、発言の長さの目安（短い／ふつう／長いをランダムに）
2. Gemini が JSON（セリフ・表情・意図・話題）で返します。
3. 直近と似すぎた発言は 1 回だけ作り直させます（これも上限に数えます）。
4. ブラウザは吹き出しに 1 文字ずつ表示し、その間キャラクターの口を動かし、表情を切り替えます。

会話の文脈はブラウザのメモリ上にだけあり、ページを閉じると消えます（localStorage などにも保存しません）。

## 開発

```bash
npm test
```

ユニットテスト（プロンプト・重複検出・上限）と、モックの Gemini サーバーに対して実際にサーバーを起動する結合テストが走ります。API キーは不要です。

```bash
npm run dev
```

ファイル変更時にサーバーを自動再起動します。

```
server/
  index.mjs         HTTP サーバー（静的配信・API・呼び出し元の確認）
  ai.mjs            Gemini API 呼び出し・エラー変換
  limits.mjs        使いすぎ防止の上限管理
  conversation.mjs  人格・プロンプト組み立て・停滞/重複検出
  demo.mjs          デモモードの簡易生成器（AI ではない）
public/
  index.html / style.css / app.js   画面とゲーム進行
test/               テスト
render.yaml         Render 用の Blueprint
```
