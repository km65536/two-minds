API キーが設定されていません

二人の会話は Claude API によってその場で生成されます。サーバー側に API キーを設定してください。キーはブラウザには送られません。

  1. Anthropic Console で API キーを発行する
  2. プロジェクト直下で .env.example を .env にコピーする
    cp .env.example .env
  3. .env の ANTHROPIC_API_KEY= にキーを書く
  4. サーバーを再起動する
    npm start
